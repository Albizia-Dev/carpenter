# Контекстный шелл рабочего приложения

`CarpenterWorkspaceShell` — экспериментальная композиция на публичных `CarpenterRootLayout`, `CarpenterSidebar`, `CarpenterTopPanel`, `CarpenterBreadcrumbs` и стандартных контролах. Добавляется рядом с `CarpenterApplicationShell`, без замены его контракта.

## Компоновка

Слева: имя продукта, переключатель рабочего раздела, только навигация этого раздела, отдельные закрепления и контекстный footer. Справа: путь страницы, переход по названию, входящие и профиль; затем уведомление о состоянии, активный звонок, сама страница и необязательный нижний статус. Нативный хост может передать свою строку управления окном.

Размеры, интервалы, фон, границы, типографика и фокус берутся из CarpenterTheme/UnitsRoot. Никаких продуктовых цветов и пиксельных breakpoint внутри компонента. По умолчанию доступное место учитывает масштаб текста.

| Среда | Навигация | Хедер |
|---|---|---|
| Wide | Раскрытая панель, rail или скрытая по решению хоста | Путь и общие действия |
| Medium | Rail, полная навигация во временном modal drawer | Действия сохраняются |
| Narrow | Полная ширина страницы, modal drawer по кнопке | Короткий контекст, поиск и профиль; при нехватке места действия переносятся |

`sidebarExpanded`, `sidebarVisible`, `sidebarOpen` независимы. Размер окна не перезаписывает предпочтение пользователя. Закрытие drawer, смена ширины и сворачивание панели не пересоздают страницу. Drawer закрывается по Escape/барьеру, удерживает фокус и исключает фон из обхода клавиатурой и семантического дерева. Вложенный диалог обрабатывает Escape первым.

## Владение состоянием

Библиотека не знает маршрутов, ролей, API, учётных записей или хранилища. Приложение передаёт разрешённые элементы, единственный selectedId и callbacks. Подтверждение ухода с черновиком остаётся у router/page guard. Notice/activity появляются только при наличии реального состояния у хоста.

`CarpenterNavigationPalette` принимает контроллер строки, уже отфильтрованные результаты, фазу запроса, ошибку и retry callback. ID результатов уникальны и непрозрачны. ArrowUp/Down пропускают недоступные пункты; Enter выбирает текущий результат, из поля — первый доступный. У недоступного сохранённого пункта можно показать причину. При обновлении или ошибке уже загруженные результаты остаются видимы.

## Widgetbook

`Layout → Shells → Contextual workspace → Playground`: 55 именованных сценариев из согласованного макета; параметры продукта, раздела, switcher, поиска, действий, навигации, footer, breadcrumbs и нативной строки. Тема, размер viewport, направление текста и масштаб — общие addons.

Каталог сценариев охватывает desktop/rail/focus, каталог и поиск, права и закрепления, loading/error/empty, входящие, профиль, обновление/сеть, черновик/сохранение/уход, сессию, звонок/конференцию, tablet/mobile/native и увеличенный текст. Данные и переходы демонстрационные. Hover/pressed/focus вызываются реальным вводом; debug-флагов в библиотеке нет. Для точного размера используйте viewport addon или отдельные mobile/tablet use cases. Сценарий «Увеличенный текст» сочетается с text-scale addon.

Поведенческие тесты проверяют сохранение редактора, Escape, адаптивность, RTL/2×, клавиатуру палитры. Widgetbook строит каждую сцену при 1440×900 и 390×844 в светлом/тёмном окружении; это не визуальное одобрение скриншотов.

## Интеграция dsktp

Адаптер приложения группирует существующий список разрешённых маршрутов, сохраняет исходные AppNavigationItem и их API-контуры. `/zakupki/project`, `/zakupki/project-new`, `/zakupki/project-plus` — три отдельных перехода. Поиск — переход по разделам, а не обещание поиска бизнес-данных. Входящие, профиль, звонки и обновления подключаются через реальные сервисы приложения; демосостояния Widgetbook не подставляются в продукт.

- Анализ новых файлов библиотеки чистый. Общий анализ содержит существующие lint-сообщения; в Widgetbook их 6, без ошибок.
- Аудит документации сохраняет старый долг других компонентов. Новые workspace API документированы и доступны из каталога; baseline уменьшен на задокументированный конструктор root layout, новый долг не добавлен.
