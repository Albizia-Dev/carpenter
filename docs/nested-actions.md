# Вложенные действия

`CarpenterActionDescriptor.group` объединяет действия в дерево. Обычные конструкторы и обработчики не изменились. `children` доступен также в обычном дескрипторе; непустой список означает подменю и имеет приоритет над `onInvoke`.

```dart
CarpenterActionDescriptor.group(
  id: 'excel',
  label: 'Excel',
  children: [
    CarpenterActionDescriptor(
      id: 'excel.all',
      label: 'Все записи',
      onInvoke: exportAll,
    ),
  ],
)
```

Группа поддерживается в CarpenterMenu и панелях действий, использующих общую проекцию CarpenterToolbar/ActionStrip. Подменю открывается в той же области, не выходит за границы узкого экрана. Внутри есть «Назад»; Enter/стрелка вправо открывает группу, влево/Escape возвращает на уровень вверх с восстановлением фокуса. Escape в корне закрывает меню. Выбор конечного действия вызывает его один раз и закрывает меню полностью.

Скрытые потомки не показываются, недоступные нельзя выполнить. Группа без доступных видимых потомков недоступна. Уровни могут быть вложены повторно; идентификаторы должны быть уникальны среди соседей. Состояние действий, доступность и переключатели остаются у вызывающего кода.

`CarpenterPageHeader.overflowActions` всегда прячет переданные действия под многоточие, независимо от доступной ширины. В отличие от secondaryActions, они не появляются снаружи на широком экране.

Пример вложенного экспорта доступен в Widgetbook → Menu → Playground. Проверки: test/behaviour/nested_actions_test.dart и menu_test.dart.

## Проверка этой доработки

- 8 профильных тестов вложенности и существующего меню прошли; анализ изменённых компонентов и страницы Projects+ — без замечаний.
- Общий набор Carpenter: 521 прошёл, один сбой `tree disclosure uses a rotating Gravity chevron` в advanced_collections_test.dart. Код дерева в этой доработке не менялся.
- Общие проверки Widgetbook не зелёные: тесты примеров редактирования/сетевого обновления/каталога и golden-сравнения требуют отдельного разбора. Эталоны не обновлялись.
- Documentation audit сообщает существующие расхождения baseline и удалённую запись CarpenterMenu.build после перехода к StatefulWidget. Новые члены API документированы; baseline не увеличивался.
- Полная web-сборка Widgetbook прервана после затянувшейся компиляции; успешная сборка не подтверждена. Desktop не запускался, публикации и push не выполнялись.
