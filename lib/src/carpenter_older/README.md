# Совместимый Carpenter

Здесь сохранена реализация `carpenter_older` 0.0.1 из
https://github.com/Albizia-Dev/carpenter_old,
коммит `ca516c7c146d657c64b0a022355f31c184c53961`.
Исходники совпадали с опубликованным пакетом 0.0.1 до переноса.

Публичная точка входа: `package:carpenter/carpenter_older.dart`.
Внутренние package-импорты перенесены в пространство имён этого каталога;
сигнатуры и поведение сохранены. Лицензия исходного пакета — Apache-2.0
(см. `LICENSE`). Существующие тесты перенесены в `test/carpenter_older/`.

Этот слой совместимости не экспортируется из современного `carpenter.dart`.
Он сохраняется внутри Carpenter для дальнейшего постепенного объединения.
Не импортируйте его внутренние файлы из новых слоёв библиотеки.
